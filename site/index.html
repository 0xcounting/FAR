Read this before you trust a link

Every DTI to CoinGecko link carries a status. They are not equally reliable.

StatusWho decidedMeasured accuracy
acceptedA human, in a reviewed pull request, citing public evidencethe only tier to rely on
proposedA deterministic rule: exact name, optionally corroborated by tickerunmeasured
inferredA language model, with its reasoning published on the recordunmeasured

Why “unmeasured”

Scoring a name-based guess needs a column of known-correct answers to grade against, and that column would be the contract address for each DTI. DTIF's free monthly snapshot redacts it, so there is nothing to grade against and any accuracy figure here would be invented. If a wrong link would cost you something, a tax filing or a regulatory report, filter to accepted and treat the rest as a candidate queue.

Expect one error above all others

A bridged or pegged deployment attached to the canonical asset it wraps. CoinGecko alone carries dozens of distinct assets whose name is “USD Coin” or close to it, bridged-usdc, celer-bridged-usdc-astar and many more, and only one of them is Circle's. A DTI record named “USD Coin” could be any of them, and the name cannot tell you which.

Verifying what you fetched

curl -s https://0xcounting.github.io/FAR/cg/tether.json | shasum -a 256
# compare against the entry for cg/tether.json in /manifest.json

The manifest also carries a Merkle root over every (path, hash) pair, so a single file can be proven to belong to a published release without downloading the rest. An inclusion proof is about 17 hashes. Builds are deterministic: same inputs, same root.

Using it in code

const BASE = 'https://0xcounting.github.io/FAR';

// by name — returns a GROUP, because names are not unique
const r = await fetch(`${BASE}/name/${slug}.json`);
if (r.status === 404) return null;            // no asset by that name
const { assets } = await r.json();

// by CAIP-19 — ":" and "/" become path separators, "%" becomes "~"
const path = caip19.replace(/:/g, '/').replace(/%/g, '~');
const one = await fetch(`${BASE}/caip/${path}.json`);
